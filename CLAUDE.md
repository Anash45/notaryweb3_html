# Repository instructions

## Git commit / PR attribution

Do not add any Claude/Anthropic attribution to commits or pull requests in
this repository. Specifically, never include:

- `Co-Authored-By: Claude ...` trailers in commit messages
- `Claude-Session: ...` trailers in commit messages
- "Generated with Claude Code" or similar footers in PR descriptions

Commits should use the repository's own configured git identity only.
